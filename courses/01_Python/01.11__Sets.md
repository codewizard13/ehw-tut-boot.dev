### ▶️ L1: Sets

<section class="callout"><span class="label-verbatim">COPIED VERBATIM:  👇🏽</span>

[Sets](https://docs.python.org/3/tutorial/datastructures.html#sets) are _like_ Lists, but they are _unordered_ and they guarantee _uniqueness_. Only _ONE_ of each value can be in a set.

```python
fruits = {"apple", "banana", "grape"}
print(type(fruits))
# Prints: <class 'set'>

print(fruits)
# Prints: {'banana', 'grape', 'apple'}
```

## [Add](https://docs.python.org/3/library/stdtypes.html#frozenset.add) Values

You can [`.add()`](https://docs.python.org/3/library/stdtypes.html#frozenset.add) values to a set. Think of `.add()` like `append` but for sets!

```python
fruits = {"apple", "banana", "grape"}
fruits.add("pear")
print(fruits)
# Prints: {'pear', 'banana', 'grape', 'apple'}
```

No error will be raised if you add an item already in the set, and the set will remain unchanged.

## An Empty Set

Because the empty bracket `{}` syntax creates an empty dictionary, to create an _empty_ set, you need to use the `set()` function.

```python
fruits = set()
fruits.add("pear")
print(fruits)
# Prints: {'pear'}
```

## Set Iteration

```python
fruits = {"apple", "banana", "grape"}
for fruit in fruits:
    print(fruit)
    # Prints:
    # banana
    # grape
    # apple
```

Note: Sets are unordered, so the order of iteration is _not_ guaranteed.

def remove_duplicates(spells):
    
    spells_seen = set()
    unique_spells = []

    for spell in spells:

            spells_seen.add(spell)
            unique_spells.append(spell)
    return unique_spells

def count_vowels(text):
    
    vowel_counts = {
      "a":0,
      "A":0,
      "e":0,
      "E":0,
      "i":0,
      "I":0,
      "o":0,
      "O":0,
      "u":0,

        #if char is a vowel

            # print(f"YES - Char {char} was found in the vowels_counts dict")

            unique_vowels.add(char)

### ▶️ L6: Set Subtraction

<section class="callout"><span class="label-verbatim">COPIED VERBATIM:  👇🏽</span>

You can use some of the "normal" mathematical operations on sets. For example, you can subtract one set from another. It removes all the values in the second set from the first set.

```py
set1 = {"apple", "banana", "grape"}
set2 = {"apple", "banana"}
set3 = set1 - set2

print(set3)
# Prints: {'grape'}
```

# Game Difficulty Scope

**Complete the `set_game_difficulty` and `get_status_message` functions.**

This challenge is about **variable scope**: when a variable is visible and can be used.

You are given a global variable:

```py
GAME_DIFFICULTY = "normal"
```

You must use this variable from inside your functions.

## Requirements

1.  `set_game_difficulty(new_level)`
    
    *   Change the global `GAME_DIFFICULTY` to the string given in `new_level`.
    *   Use the [`global` keyword](https://docs.python.org/3/reference/simple_stmts.html#the-global-statement) so that you update the global variable, not a new local one.
2.  `get_status_message(player_name)`
    
    *   Read the current value of the global `GAME_DIFFICULTY`.
        
    *   Return a string in this exact format:
        
        ```py
        "<player_name> is playing on <GAME_DIFFICULTY> difficulty"
        ```
        
    *   Replace `<player_name>` with the value of `player_name`.
        
    *   Replace `<GAME_DIFFICULTY>` with the current global value.
        

## Scope behavior to keep in mind

*   A variable defined outside any function (like `GAME_DIFFICULTY`) is **global**.
    
*   Inside a function, if you assign to a name, Python treats it as **local** by default.
    
*   To modify a global variable from inside a function, you must declare it as global:
    
    ```py
    def set_game_difficulty(new_level):
        global GAME_DIFFICULTY
        GAME_DIFFICULTY = new_level
    ```
    
*   Simply _reading_ a global variable inside a function does **not** require the `global` keyword.
    

## Examples

```py
from main import set_game_difficulty, get_status_message

print(get_status_message("Alice"))
# "Alice is playing on normal difficulty"

set_game_difficulty("hard")
print(get_status_message("Bob"))
# "Bob is playing on hard difficulty"

set_game_difficulty("easy")
print(get_status_message("Cara"))
# "Cara is playing on easy difficulty"
```

Your job is to make both functions work exactly as described above.
